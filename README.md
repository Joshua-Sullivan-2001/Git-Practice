# My Version Control Practice
# This repository belongs to Joshua Sullivan. I am learning how to use Git and GitHub.
## Skills practiced
* Local repository initialization using git init
* Configuring global user identity names and emails
* Staging changes using git add
* Creating commits with descriptive tracking messages
* Reviewing commit history timelines using git log
* Inspecting modifications and untracked files using git status and git diff
* Operating the integrated terminal interface within VS Code
* Utilizing the graphical VS Code Source Control panel to stage and commit
* Creating and switching default branches using git branch
* Connecting local project folders to online remotes using git remote
* Uploading local histories to cloud repositories using git push
* Modifying code files and committing changes directly on the GitHub website
